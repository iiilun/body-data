# BODY / DATA · V5

[公開作品](https://iiilun.github.io/body-data/) · [同學測試說明](TESTING.md) · [回報問題](https://github.com/iiilun/body-data/issues/new/choose)

JavaScript、Canvas 2D、CSS 3D、MediaPipe 與 Matter.js 的六面身體互動作品。影像只在瀏覽器本機處理，不上傳、不保存。無前端框架與建置步驟。

## 啟動與操作

使用電腦版 Chrome；開啟網站按 ENTER，允許鏡頭。一次一人，上半身、手肘與雙手完整入鏡。F 切換全螢幕。

1. 張開手掌向外撥動方塊，再將手收回。回手不會把方塊轉回；可連續撥動，看見六個面。
2. 停手後吸附選面，正面變白；握拳約0.34秒確認。尚未停穩或直接以拳頭入鏡不會誤選。
3. 兩組數據各展示3秒，再進入線條人物外輪廓。對齊身體並維持指定姿勢3秒，自動開始。
4. 每關45秒，結束數據展示7秒，再回選單。雙拳舉至頭旁1.5秒或返回箭頭可提前返回；選單 END 關閉鏡頭。

## 六種互動

- **SHELTER**：紅光、加速流動的氣候資料及累計排放估算。頭上的手掌遮蔽下方身體；未保護的原色像素持續脫落並受重力落下。耗損以身體部位記錄，回手或移動不會重建已掉落的材料。
- **HOLD**：人物向下移，縮小的標題、數值、地區與年份持續落到雙臂。數據剛體能完整旋轉、堆疊、碰撞、滑落，胸口有連續支撐。5:2的落點分配引用2.5倍無酬照顧時差；堆積使虛擬手臂下沉。物理重量是藝術轉譯，不將不同統計單位相加。
- **SPACE**：密集而小的住房數據填滿空間，保持句子與列的身份，以彈簧運動為身形讓路，沒有切換透明度的閃爍。人物可用空間隨時間壓縮。
- **THIRST**：雙手持三條線構成的桶，移動接取全畫面的雨；手臂一高一低可傾倒。藍色代表安全管理服務，赭色代表安全無法確保。一滴赭色就使整桶水安全無法確保，倒空後才能重新收集。結束顯示安全量、安全無法確保的量，以及依WHO緊急基本供水15 L／人日換算的情境量；不是兒童飲水需求。
- **OFFLINE**：左側人物與數據流暢、原色，右側兩者一起失去色彩、延遲、缺塊，約每1.4秒更新。移動身體跨越分界，直接感受資訊取得差異。這是連線差異的藝術設定，不是假稱量測到的丟包或網速。
- **VACANT**：120戶城市格網依日本2023空屋率13.8%呈現約17個白框空屋。用一手握拳拿起空屋，帶到身體旁，張手後在身邊重新使用；房子移動並保留，不會直接消失。畫面與結束計數明標為再使用情境。空置不等於可入住，不捏造可取得率，也不把各國空屋數相加成全球總數。

## 全球資料與七語

英文、西文、法文、繁中、日文、韓文、阿拉伯文共用同一批全球與各國比較資料，語言只改文字、數字格式與地名。每關至少24筆，均保留指標名稱、年份、地區、來源與定義。UN、UN-Habitat、UN Women、UNSD、ILO、WMO、WHO／UNICEF JMP、ITU、World Bank與各國官方普查為主要來源。

- `dist/assets/global-facts.json`：V5正式資料、七語標籤及互動比例。
- `research/v5-global-sources.md`：逐筆來源、觀測期間、口徑與分類限制。
- 選單 DATA 可檢視所有資料的來源連結；官方數據是定期觀測快照。碳排年度率另嘗試更新，停留期間累計值以年度平均率估算。背景移動不代表官方統計逐秒重新發布。
- 舊的 `data.json`、`extra-facts.json`、`regional-access.json` 與V4研究保留作歷史來源與驗證；V5不再按介面語言篩選資料地區。

## 本機開發與預覽

Node.js 20以上，在此目錄執行 `npm start`，開啟 http://localhost:5173。正式網站使用HTTPS，開發使用localhost。

PREVIEW不開鏡頭，使用Google官方測試照片的原色馬賽克。拖曳方塊，空白鍵模擬握拳；1–6選主題。飲水的游標模擬雙手，按住滑鼠可傾倒；空屋按住拖曳、放開釋放。SPACE與OFFLINE的游標可移動示範人物。這些操作供設計預覽，並非相機辨識驗證。

```text
http://localhost:5173/?demo=1&scene=hold
http://localhost:5173/?demo=1&scene=space&time=22&still=1
http://localhost:5173/?demo=1&scene=thirst&intro=1&frame=1
```

`intro=1`停在數據介紹，空白鍵進對位；`frame=1`停在對位，預覽空白鍵可進關。`still=1`與`time=`供固定排版檢查；正式鏡頭流程沒有這些捷徑。

## 驗證與部署

`npm test` 檢查選面回手、停穩握拳、姿勢倒數、全畫面投影、原色馬賽克、持續耗損、遮蔽、剛體承接、彈性文字、接水污染與傾倒、空屋搬移，以及七語資料一致性。GitHub Actions驗證通過後部署`dist/`到GitHub Pages。

人體辨識使用獨立Worker：Pose Lite、雙手21點與Selfie Landscape去背；推論寬480，保留相機比例。主執行緒取樣寬128、32欄原色正方形馬賽克，繪製與推論分離；數據排版與量測均快取。

模型照片測試要求33身體點、雙手各21點、非空的人物遮罩，且中心為人物、角落為背景。測試照片不能代表M4搭配實際網路鏡頭的FPS，現場仍需確認光線、遮擋和手臂入鏡範圍。參見`tests/fixtures/vision-browser/README.md`。

阿拉伯文使用隨站附帶的Noto Sans Arabic（SIL Open Font License），其他語言優先使用Helvetica／系統無襯線字。MediaPipe採Apache 2.0，Matter.js採MIT；來源與授權在`dist/vendor`。
