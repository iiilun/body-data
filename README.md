# BODY / DATA · V5.10.0

[公開作品](https://iiilun.github.io/body-data/) · [同學測試說明](TESTING.md) · [回報問題](https://github.com/iiilun/body-data/issues/new/choose)

JavaScript、Canvas 2D、CSS 3D、MediaPipe 與 Matter.js 的六面身體互動作品。影像只在瀏覽器本機處理，不上傳、不保存。無前端框架與建置步驟。

## 啟動與操作

使用電腦版Chrome。進入頁面即要求相機權限，與資料載入、入口動畫並行。手部模型就緒後，張手指向一顆語言立方體，停留3秒選擇；七顆方塊聚合成中央選單。一次一人，上半身、手肘與雙手完整入鏡。

返回、全螢幕、資料都是緩慢漂浮旋轉的小立方體，六面顯示同一個圖示。返回與資料以張手停留3秒觸發，離開後才可再次選取；全螢幕只接受實際點擊或F鍵，不參與手部感應、停留進度或計時暫停。正式互動期間隱藏這三顆方塊與手部游標，結果頁恢復顯示。資料頁左上角返回方塊獨立於捲動區；捏合拇指與食指，上下拖動資料，放開立即停止。瀏覽器若限制全螢幕，顯示明確的相容提示。沒有END按鈕；離開頁面時停止相機。

1. 方塊緩慢自轉，72秒繞一圈，並傾斜展示上下表面。方塊固定在畫面正中央；握拳向四周拖曳可改變旋轉角度，張手後保留目前角度。選單優先右手，操作中固定同一隻手；另一手出現或模型回傳順序改變不會奪走控制權。旋轉有微小死區、較低倍率與平滑；張手／握拳需穩定95ms才切換。
2. 張手指到實際要選的面，該面變白且暫停自轉。大圓形累積3秒後進入；換面、離開、握拳或持續失追均重置。短暫預測影格保留白面但不增加倒數；重新追蹤後重新錨定。六面顯示參考圖示與單一標題，選取時黑白反轉。
3. 選定後，方塊先掀蓋，四側沿相連折線依序展開成六面刀模。中央內面直接呈現該關的實際說明頁，整張展開圖保持相連並一起向前靠近，直到有資訊那格填滿視窗，才開始兩組數據各3秒的閱讀計時。轉場約3.95秒；沒有先前的黑色空隙放大或黑幕。
4. 接著展示6秒文字與人形動作示範：依提供的參考圖，以三道相近、略錯開的連續圓滑外輪廓構成人形；黑底白線、白底黑線，各關延伸相應動作。
5. 再進入未去背的完整黑白鏡頭，以畫面混合去色並疊48%黑色，讓影像明顯變暗，不依賴Canvas濾鏡支援。實際人物遮罩產生12px白色外輪廓，與人物間保留約12px間距；姿勢與遮罩均有效時，輪廓平滑轉成20px綠線，間距維持不變，中央顯示大型3秒倒數。輪廓經空間柔化、均勻弧長平滑、次像素追蹤與跨影格平滑，短暫漏偵測不會立刻閃掉。完成後才進入去背互動。
6. 每關45秒，結束數據以同一條進度線展示7秒，再自動回選單。返回方塊停留3秒可提前回選單；主選單的返回方塊回到語言頁，保留相機與追蹤。閱讀6秒、動作示範6秒、對位3秒及結果7秒的進度均使用2px細線；白底HOLD／THIRST用深色，黑底用白色。指向工具或閱讀資料面板時，關卡及頁面計時暫停。

## 六種互動

- **SHELTER**：紅光、加速流動的氣候資料及累計排放估算。頭上的手掌遮蔽下方身體；只有本關的人物使用熱成像假色，未保護的像素持續脫落並受重力落下。受紅光照射的背景文字有熱膨脹、平滑扭曲和輕微模糊；頭上手掌和舉起的手臂產生陰影，陰影內立即恢復清晰，重新曝曬後再扭曲。色彩是藝術轉譯，並非相機測溫。耗損以身體部位記錄，回手或移動不會重建已掉落的材料。
- **HOLD**：人物向下移，縮小的標題、數值、地區與年份持續落到雙臂。數據剛體能完整旋轉、堆疊、碰撞、滑落，胸口有連續支撐。5:2的落點分配引用2.5倍無酬照顧時差；堆積使虛擬手臂下沉。最大負重時手腕可下沉畫面高度38%，並有緩慢疲勞累積。物理重量是藝術轉譯，不將不同統計單位相加。
- **SPACE**：12–18px住房數據填滿空間，列距約字級0.98倍、字距略為負值，保持句子與列的身份，以柔和延遲的彈簧運動為身形讓路。障礙邊界約260ms追隨、移開後約480ms回流，再柔化位移目標；字元位置不做瞬間修補，完整數值一起移動，循環只在充分離屏處換位。人物可用空間隨時間壓縮。
- **THIRST**：白色霧面玻璃。以原始人物去背遮罩呈現有深度的模糊黑影，手與身體共用相同的柔和陰影，不另疊清晰或加深的手掌；不使用人物RGB或馬賽克。張開雙手擦拭，連續的掌印和指痕會露出背後的24筆全球飲水資料。水珠被推到擦痕邊緣，聚合後受重力流下；擦過後保留5秒，再逐漸重新凝結。霧層比V5.3更厚。手掌大小、肩寬與姿態相對深度用於估計接觸與模糊程度，並非量測距離。結算區分個人抹清面積與WHO／UNICEF JMP的全球安全飲水服務缺口，不再使用水桶、情境公升或供水人日。
- **OFFLINE**：左側原色流暢；右側保持人物可見，動作與資料以5 Hz階段更新，延後約0.22–0.42秒。人物位置跟隨目前身體，肢體姿勢取短期歷史，因此跨到右側不會只留下數秒前的位置；灰階亮度設可見下限，缺塊比例降至3.5%。
- **VACANT**：120戶城市格網依日本2023空屋率13.8%呈現約17個白框空屋。用一手握拳拿起空屋，帶到身體旁，張手後在身邊重新使用；房子移動並保留，不會直接消失。畫面與結束計數明標為再使用情境。空置不等於可入住，不捏造可取得率，也不把各國空屋數相加成全球總數。

其他五關背景維持畫面高3.2%（20–31px）、0.98倍列距與−0.055em字距；SPACE使用更小、更細密的字級及柔和避讓。流動資料預先繪製為文字圖集；熱浪只處理資料層，人物和操作介面保持獨立。

## 全球資料與七語

英文、西文、法文、繁中、日文、韓文、阿拉伯文共用同一批全球與各國比較資料，語言只改文字、數字格式與地名；右上方不再有語言下拉選單，改由入口方塊選擇。每關至少24筆，均保留指標名稱、年份、地區、來源與定義。UN、UN-Habitat、UN Women、UNSD、ILO、WMO、WHO／UNICEF JMP、ITU、World Bank與各國官方普查為主要來源。

- `dist/assets/global-facts.json`：V5正式資料、七語標籤及互動比例。
- `research/v5-global-sources.md`：逐筆來源、觀測期間、口徑與分類限制。
- 選單 DATA 可檢視所有資料的來源連結；官方數據是定期觀測快照。碳排年度率另嘗試更新，停留期間累計值以年度平均率估算。背景移動不代表官方統計逐秒重新發布。
- 舊的 `data.json`、`extra-facts.json`、`regional-access.json` 與V4研究保留作歷史來源與驗證；V5不再按介面語言篩選資料地區。

## 本機開發與預覽

Node.js 20以上，在此目錄執行 `npm start`，開啟 http://localhost:5173。正式網站使用HTTPS，開發使用localhost。

PREVIEW不開鏡頭；游標模擬張開的手，語言與工具同樣停留3秒。資料頁按住滑鼠上下拖動可模擬捏合。飲水關使用程序化黑影與手部示範，其他關使用Google官方測試照片的原色馬賽克。按住滑鼠拖曳旋轉主方塊，放開後指向實際表面停留3秒；1–6選主題。飲水關以游標移動一隻張開的手擦拭，另一隻手留在示範姿勢；空屋按住拖曳、放開釋放。SPACE與OFFLINE的游標可移動示範人物。原生點擊及鍵盤保留作相容入口；這些預覽操作並非相機辨識驗證。

```text
http://localhost:5173/?demo=1&scene=hold
http://localhost:5173/?demo=1&scene=space&time=22&still=1
http://localhost:5173/?demo=1&scene=thirst&intro=1&frame=1
```

數據介紹6秒後自動進入動作示範；舊的`intro=1`不再停住流程。`guide=1`停在動作示範，空白鍵進鏡頭對位；`frame=1`停在對位，預覽空白鍵可進關。`step=guide`或`step=align`可直接檢查該頁；`ready=1&frame=1`可在預覽固定綠色輪廓與數字3。`still=1`與`time=`供固定排版檢查；正式鏡頭流程沒有這些捷徑。

## 驗證與部署

`npm test`檢查入場與合併順序、語言選擇、多手三秒停留、失追重設、同位置重觸鎖定、工具優先權、頁面倒數與進度、不同尺寸方塊配置、減少動態效果設定、自轉、相對角度拖曳、六面圖示對應與標題適配、共用密集字級、受光／陰影熱浪、姿勢倒數、全畫面投影、原色馬賽克、持續耗損、遮蔽、剛體承接、彈性文字、霧氣擦拭與回凝、水珠推移及聚合、空屋搬移，以及七語資料一致性。GitHub Actions驗證通過後部署`dist/`到GitHub Pages。

人體辨識使用獨立Worker：Pose Lite、Gesture Recognizer（雙手21點＋內建手勢分類）與Selfie Landscape去背；推論寬480，保留相機比例。主執行緒使用48欄原色正方形馬賽克，格子邊長為先前的三分之二（飲水關保留模糊陰影），繪製與推論分離；數據排版與量測均快取。選單每影格先辨識手並立即回傳，每三個影格才更新一次身體與遮罩；遊戲保持完整身體管線。手勢模型啟動失敗時保留舊Hand Landmarker備援。六關都以完整視窗高度繪製；體驗中不顯示底部資訊條、數值摘要或漸層遮罩，也不預留背景空間；關卡資訊與數值摘要在開場、結束畫面呈現。

模型照片測試要求33身體點、雙手各21點、非空的人物遮罩，且中心為人物、角落為背景。測試照片不能代表M4搭配實際網路鏡頭的FPS，現場仍需確認光線、遮擋和手臂入鏡範圍。另以Google官方fist.jpg檢查Closed_Fist分類。參見`tests/fixtures/vision-browser/README.md`、`research/v51-interaction.md`與`research/v52-heat-and-menu.md`。

阿拉伯文使用隨站附帶的Noto Sans Arabic（SIL Open Font License），其他語言優先使用Helvetica／系統無襯線字。MediaPipe採Apache 2.0，Matter.js採MIT；來源與授權在`dist/vendor`。
