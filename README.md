# BODY / DATA · V4

同學測試請先看 [測試說明](TESTING.md)。本倉庫會以 GitHub Actions 驗證並發佈 `dist/` 到 GitHub Pages。

用 JavaScript、Canvas 2D、CSS 3D、MediaPipe 0.10.35 與 Matter.js 0.20.0 製作的六面身體互動作品。影像在瀏覽器本機處理，不上傳、不保存。沒有前端框架或建置步驟。

## 啟動

使用新版 Chrome、Node.js20以上，在此目錄執行：

```sh
npm start
```

開啟 http://localhost:5173，也可雙擊「啟動作品.command」。正式網站使用 HTTPS。初次需按 ENTER 允許鏡頭；瀏覽器的相機權限需要使用者操作一次。

將鏡頭朝向一人上半身，讓頭、肩膀、手肘及雙手可完整入鏡。建議全螢幕展示，F切換全螢幕。

## 全身體操作

1. 開啟相機後，張開手掌移動，直接旋轉中央方塊，水平與垂直移動可看到六個面。
2. 握拳約0.38秒，選擇當前最朝向觀眾的面。選擇前必須先有張手動作，避免剛入鏡的拳頭誤觸。
3. 先看6秒的大數據說明，再進入姿勢輪廓畫面。
4. 將頭與身體置中、雙手完整入鏡，做出對應姿勢。符合條件時輪廓變綠，維持3秒倒數後自動開始；姿勢離開超過0.22秒重置倒數。沒有 BEGIN 按鈕。
5. 每段45秒，之後保留數據7秒，再回到方塊。雙拳舉至頭旁保持1.5秒可提前回選單；也保留返回箭頭。
6. 選單 END 關閉鏡頭；Esc在關卡回選單、在選單關閉鏡頭。語言選項可用滑鼠。

## 六個面

**SHELTER / 高溫與排放**：紅光向下推進。人物保持原色與正方形像素，受熱後逐顆脫離、受重力落下，不把整個人壓成扁平。抬手能保護下方一列、揮手減緩熱場並推動掉落像素；紅光只有柔和漸層，沒有波浪邊界線。排放計數依年度排放率平均換算，與手勢冷卻的視覺反應分開，不宣稱手勢改變真實排放或個人熱傷害。

**HOLD / 無酬照顧**：標題、數值、地區與年份一起成為可旋轉的剛體，承接、翻轉、碰撞與滑落。肩膀至手腕都有活動支撐，胸口有連續碰撞面，避免數字穿進身體。資料不再只有2.5×與1×：全球包括時間差距、照顧造成的勞動力退出、每日照顧總時數與估值；臺灣包含家務、直接照顧、志工、兒童與高齡照顧等。不同口徑與年份各自標示，不加成一個總數，不推測觀眾性別。重力向下，物體角度可完整旋轉，手臂移動提供慣性與碰撞反應。

**SPACE / 居住空間**：數據與標題逐字排入人物輪廓以外的空間。移動身體與手掌時，文字重新讓路；人物的水平空間卻隨時間逐漸縮小。每字保留正常字距，沒有整排數字被推成重疊字團。全球包含都市聚落比例、人數、住房不足及跨年度驅離估計；臺灣包含全國與六都的房貸負擔和房價所得比。場景中的擠壓是藝術轉譯，不是身體尺度的統計模型。

**THIRST / 飲水**：雙手靠攏成接水口，引導藍色像素水流，供給會間歇中斷。數據涵蓋安全管理飲水、取水時間、地表水等服務層級。臺灣用自來水普及、未接管家戶與漏水等官方指標，明示其名稱，不冒充JMP安全飲水指標。水流節奏是藝術設定，不把缺乏服務的人數換算成每秒新增受害者。

**OFFLINE / 數位落差**：人物被分成不同延遲、停格與缺失的區域，真實身體仍持續移動。揮手可讓局部重新同步，之後又失去連結。資料分別標示使用者、未使用者、城鄉與性別；臺灣的「曾經使用網路」與ITU「近三個月使用」保留各自名稱。影像缺失率不是統計人口比例或實際網路丟包率。

**VACANT / 空屋**：大面積空白房間讓人物被隔在其間。把雙手放進同一間房間，可逐漸讓自己的影像出現，移開後房間恢復空白。空置與能否取得住房形成對照。臺灣使用2020正式住宅普查的空閒、目前未使用與偶爾自住等分類；英文使用明確列名國家的普查觀測，沒有虛構世界空屋總數。各國空屋分類不同，不直接加總或宣稱同口徑排名。

## 視覺、攝影機與效能

- 原色馬賽克改為寬32格（4:3時32×24；16:9時32×18），比前版52格更粗。每格平均人物內原始RGB，不套灰階。
- 影像與關節使用同一個全畫面cover映射，沒有中央限定偵測方框；相機比例與螢幕不同時會裁切邊緣，對位輪廓會要求雙手留在可見畫面內。
- 相機預設請求1280×720，推論縮至寬480並保持原始長寬比，不把寬銀幕影像擠成4:3。
- Worker使用 Pose Lite、21點雙手以及約250KB的Selfie Landscape去背模型，每個處理影格更新人物遮罩；不再載入16MB多類別去背或9MB Full Pose。主模型合計約14MB，另有WASM。
- 關節使用自適應平滑與有限55ms預測，過期手掌與身體點失效。原色取樣用低解析畫布，影像遮罩依肩膀中心最新位置補償短期平移。
- 曾測試直接使用姿勢模型的分割輸出，在開發瀏覽器出現空白遮罩／CPU錯誤，未採用。正式管線已用Google官方測試照片驗證33身體點、雙手各21點、非空且方向正確的人物遮罩（人物中心1、背景角落0）。測試肖像縮至480×752，暖機兩影格約52.6/45.1ms；此尺寸比常見16:9推論影格更高，並非M4實際攝影機幀率。

請在預計展示的M4、實際網路鏡頭、燈光及瀏覽器下試跑。攝影機遮擋、逆光與雙手離開畫面仍會影響辨識；本機測試照片不能代替現場驗收。

## 語言與資料

七語：英文全球、繁體中文臺灣，其餘依既有西／法／日／韓／阿語地區集合。新飲水與網路資料採WHO/UNICEF JMP、ITU經World Bank提供的2024同年人口與比例。加總只含有資料國家，估算人數加≈，並顯示涵蓋範圍。韓語新兩項只有南韓資料，因此直接標南韓，北韓缺失不當0。空屋只有國別觀測，直接寫國家。

資料來源與指標定義在選單 DATA。每張活動數據卡都帶地區與年份，多年份場景也會提示；來源檔案與計算規則在：

- `research/README.md`：原三個議題的來源與計算。
- `research/v4-sources.md`：新增數據、臺灣分項與各國空屋定義。
- `research/v4-regional.md`、`refresh_v4_regional.py`：同年人口加權、缺值與覆蓋規則。
- `dist/assets/extra-facts.json`：查核後的數據卡與指標說明。
- `dist/assets/regional-access.json`：飲水與網路語言地區估算。

資料多為官方定期發布，不是即時觀測。每次開啟仍嘗試更新World Bank碳排年度資料，其餘快照需查核新發布後更新。來源年份不同時不將數值解讀成同一時點；估價、歷史累計與現況存量也分別標示。

## 預覽與驗證

PREVIEW使用Google官方pose.jpg轉成的原色取樣人像，選單及頁籤有預覽標記。拖曳方塊旋轉，空白鍵模擬握拳。正式相機使用手掌與拳頭；沒有滑鼠關卡選單。

```text
http://localhost:5173/?demo=1&scene=hold
http://localhost:5173/?demo=1&scene=space&time=24&still=1&lang=zh
http://localhost:5173/?demo=1&scene=vacant&intro=1
```

預覽可用1–6選擇主題。`intro=1`固定數據導入，空白鍵進對位；`frame=1`固定對位，僅預覽可再按空白鍵進關卡；`still=1`固定互動時間以檢查排版。正常預覽使用模擬姿勢完成倒數，不代表相機辨識成功。THIRST／VACANT預覽游標模擬靠近的雙手。

```sh
npm test
```

測試包括六面法線與手掌轉動、握拳防誤選、六種姿勢與三秒倒數中斷、全畫面投影、原色像素、自由旋轉與胸口碰撞、像素脫落與遮蔽、文字避開輪廓，以及七語資料的定義、年份、覆蓋與來源。

可暫時將 `tests/fixtures/vision-browser` 複製到 `dist/qa`，以官方照片執行模型檢查。檢查同時要求遮罩中心與角落的語意正確。發佈前移除 `dist/qa`。

## 程式閱讀

1. `dist/src/app.js`：方塊→數據→姿勢→倒數→互動→返回的狀態。
2. `dist/src/controls.js`：六面旋轉、握拳、姿勢與倒數。
3. `dist/src/interaction.js`：關節平滑、手掌、握拳與失效。
4. `dist/vision-worker.js`：MediaPipe推論與人物遮罩。
5. `dist/src/renderer.js`：六個場景與原色人物。
6. `dist/src/rigid-physics.js`：Matter.js剛體、人物碰撞與獨立像素重力。
7. `dist/src/spatial-type.js`：輪廓外的逐字排版。
8. `dist/src/catalogue.js`、`extra-labels.js`：七語數據卡、涵蓋與來源。

MediaPipe為Apache2.0，Matter.js為MIT；來源與授權在 `dist/vendor`。所有研究使用公開統計，沒有觀眾攝影機影像。
